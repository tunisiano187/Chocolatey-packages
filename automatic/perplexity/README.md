# Perplexity AI

Perplexity is an AI-powered search engine and assistant that delivers accurate, real-time answers with cited sources. Ask questions in natural language and get synthesized, conversational responses backed by live web search and transparent citations.

The Windows desktop app brings the full Perplexity experience to your desktop, including AI search, Personal Computer (local-file and Microsoft 365 integration), and always-on assistant capabilities.
